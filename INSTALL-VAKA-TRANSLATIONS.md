# Install: Vaka Dālbhi source translations

1. Unzip into `F:\github\homer-sanskrit`, preserving the folder structure.
2. Open Obsidian → `Comparative Studies`. Two new notes contain the full Sanskrit of the Vaka episode in KS 10.6 (with immediate ritual explanation) and Vāmana Purāṇa 39.25–35, each with an English translation.
3. Run `ADD-VAKA-SOURCE-LINKS.bat` to insert links into the existing comparative HTML page and Obsidian study **without overwriting either**. It is safe to run twice.
4. Visit `site/comparative/vaka-dalbhya.html` locally, then test the two new links. The English sections are collapsible, closed by default.
5. Commit and push in GitHub Desktop. These two new HTML pages are static, so the ordinary build script does not regenerate them.

Source witnesses: Kāṭhaka Saṃhitā 10.6 via Sanskrit Wikisource; Vāmana Purāṇa 39.25–35 via TransLiteral. See source links inside the pages.

**Scope and textual caution:** KS 10.6 contains much more ritual prose than the Vaka episode. This edition translates the complete *episode and immediately accompanying explanations*, not unrelated ensuing rites. A compressed phrase in the KS narrative and Vāmana 39.29 merit checking in printed editions. The Sanskrit is copied with spacing added for study; compare the diplomatic source for exact sandhi and orthography.
