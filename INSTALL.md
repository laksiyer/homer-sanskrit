# Vaka Dālbhi comparison update

1. Back up your project before installing.
2. Extract the ZIP **contents** to `F:\github\homer-sanskrit` (not into a nested folder).
3. Run `INSTALL-VAKA.bat` to append the new lexicon note without overwriting existing entries. This also runs your existing `build-website.bat`.
4. Open `site/index.html`, choose Iliad 1.22–42 and select line 35 or show all passage notes. Click the comparative study link. Alternatively open `site/comparative/vaka-dalbhya.html` directly.
5. Commit and push changed files via GitHub Desktop. The separate comparative page is published as a static file.

New files: a comparative Obsidian note, a website comparative study page, the installer, and a lexicon-entry snippet. No existing Sanskrit passage is overwritten, and the main build.py/template.html are untouched.

The full original Sanskrit texts remain at the linked primary sources. The study page reproduces **selected extracts**, not the complete source texts. Chapter numbering for the epic varies across editions.
