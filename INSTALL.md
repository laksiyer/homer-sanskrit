# Homer in Sanskrit: Apollo–Rudra bow parallel update

This update retains **रजतधनुषो** in Iliad 1.49 and adds the parallel with Rudra’s **golden bow** from Atharvaveda (Śaunaka) 11.2.12, with clickable source references. The note does not discuss whether a Vedic silver bow is attested.

## Install

1. Back up any personal edits to `obsidian-vault/Iliad/Book-01/1-43-60.md` and `obsidian-vault/Reference/Comparative Lexicon.md`.
2. Extract the ZIP contents into `F:\github\homer-sanskrit`, keeping the folder structure, and replace those two files.
3. Run `build-website.bat` and open `site/index.html` to review the note.
4. Commit and push in GitHub Desktop to publish the changes.

This patch contains only the two Markdown files and this instruction file. It leaves the site builder, template, and other passages untouched. It includes the previous Smintheus/आखुपतिः material found in the earlier lexicon version; compare before replacing if you made newer edits.
