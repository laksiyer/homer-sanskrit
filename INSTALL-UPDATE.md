# Homer in Sanskrit, Iliad 1.61–100

This archive **only adds** two new Obsidian Markdown passages. It does not overwrite `scripts/build.py`, `site/template.html`, existing manuscript notes, or your interactive word-link installer.

1. Extract to `F:\github\homer-sanskrit` keeping paths intact.
2. Open the new notes in Obsidian under `Iliad/Book-01`.
3. Review the draft, particularly Greek names, ritual terms, and the Sanskrit prose.
4. Open `LEXICON-ADDITIONS.md` and merge only entries you want into `obsidian-vault/Reference/Comparative Lexicon.md`. **Do not duplicate existing headings**: Διός, θύγατρα, μῆνις or ἑκηβόλος might already be present. Extend their **Lines:** values instead. Your builder requires unique, regular headings.
5. Run `build-website.bat`. Your site should now show 1.61–83 and 1.84–100 alongside existing passages.
6. Open `site/index.html` locally; test Greek line selection, the English disclosure, and Sanskrit-linked words before publishing through GitHub Desktop.

The Greek romanization is an accent-free scholarly reading aid. Greek spelling is retained in the original column. The English is **our own literal reading aid**, not the Murray translation itself. Sanskrit IAST was generated mechanically and should be reviewed against Devanāgarī, particularly around sandhi and foreign proper nouns.
